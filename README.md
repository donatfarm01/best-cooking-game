Sizzle Station — a fast little kitchen game built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC. Run a one-chef kitchen through a 150-second lunch shift: grab ingredients from the pantry, chop them on the board, cook them in the wok, plate each dish and serve it at the pass before its ticket runs out. Six recipes share eight ingredients, so every order is a route-planning puzzle; serve on time to build a combo, and watch the rush hour at the end of the shift.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: the game is static files under game/, with keyboard (WASD or arrows, E to interact, 1-8 at the pantry, P to pause, M to mute) and mouse controls, and synthesized WebAudio sounds.
